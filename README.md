# Исследовательский проект: анализ пользовательской активности Dota 2

Репозиторий содержит материалы лабораторных работ по подготовке и интерактивному анализу учебного набора данных о пользовательской активности игры Dota 2.

## Содержание

- `Лабораторная_работа_9.docx` — материалы лабораторной работы № 9.
- `Отчет_ЛР10_Интерактивные_дашборды.docx` — отчёт по лабораторной работе № 10.
- `dota_interactive_dashboard.html` — интерактивный дашборд для анализа пользовательской активности.

## Запуск интерактивного дашборда

1. Скачайте файл `dota_interactive_dashboard.html`.
2. Откройте его в современном веб-браузере.
3. Используйте фильтры, чтобы исследовать показатели и сравнивать сегменты пользователей.

## Данные

Данные и результаты, представленные в учебных материалах, предназначены для учебного анализа. Их интерпретацию следует выполнять с учётом описания и ограничений, указанных в отчётах лабораторных работ.
